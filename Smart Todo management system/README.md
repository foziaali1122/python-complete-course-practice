# Smart Todo Management System

A modern and professional Todo Management App built with Python and Streamlit.  
This project helps users manage daily tasks with priorities, due dates, task status, charts, filters, and a clean glassmorphism UI.

---

# Live Project
[https://todo-management-app-4hkcbmgmnpacbjmzsz7nta.streamlit.app/]

---

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Task priorities (High / Medium / Low)
- Due dates
- Search and filter tasks
- Auto save using JSON
- Interactive dashboard
- Pie chart and line chart analytics
- Professional dark UI
- OOP based clean structure

---
